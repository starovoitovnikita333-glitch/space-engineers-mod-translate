# SE Localization Tool

GUI-приложение для локализации модов **Space Engineers**. Сканирует `.sbc` и `.resx` файлы модов, извлекает строки для перевода, помогает переводить их через нейросеть, импортирует обратно и инжектит в моды.

---

## Возможности

- 🔍 **Сканирование модов** — находит все строки `<DisplayName>`, `<Description>`, `<Tooltip>`, `<PublicName>` в `.sbc`, а также пары `name/value` в `.resx`.
- 📝 **Редактор перевода** — видишь оригинал и поле для ввода перевода рядом. Поддерживает фильтры «Все / Переведённые / Непереведённые / Проблемные».
- 📤 **Экспорт / импорт TSV** — переводи в Excel, нейронке или вручную. Программа понимает и TSV, и обычный текст, и CSV.
- 🎯 **Диагностика по строкам** — показывает, что реально применилось в файле, а что нет. Ищет расхождения после инжекта.
- 💾 **Автосохранение** — правки в редакторе сохраняются в `master_ru_fixed.tsv` через 0.8 сек после окончания ввода.
- 🔄 **Откат** — кнопка «Отменить последнее сохранение» откатывает TSV к состоянию до серии правок. Бэкап создаётся один раз на сессию.
- 🛡️ **Бэкапы модов** — перед инжектом можно сделать копии всех затрагиваемых файлов (`.bak_YYYYMMDD_HHMMSS`).
- 🖱️ **Применить мод** — точечный инжект + бэкап + диагностика только для выбранного мода.
- 🎨 **Масштаб интерфейса** — `widget_scaling` для чтения без лупы.
- 🔀 **Копирование/вставка** — Ctrl+C / V / X / A / Z / Y работают на любой раскладке, включая русскую.
- 🌐 **Локализация как локализация** — корректно работает с `.resx` (то, что ванильная игра использует через `{LOC:...}`).

## Установка

1. Клонируй репозиторий или скачай `se_gui.py` из релизов:

```
git clone https://github.com/ТВОЙ_НИК/se-localization-tool.git
cd se-localization-tool
```

2. Запусти:

```
py se_gui.py
```

3. В верхнем поле укажи путь к папке модов:

```
F:\Steam\steamapps\workshop\content\244850
```

4. Нажми **«Загрузить список»**.

## Быстрый старт

### 1. Настройка

- **Папка модов** — путь к workshop Space Engineers (`...\content\244850`).
- **Папка локализации** — куда складывать TSV и бэкапы (`loc_dir`). По умолчанию `...\workshop\loc`, задаётся в конфиге.

### 2. Сканирование

- **Сканировать всё** — обходит все моды, пишет результат в `master.tsv`.
- Или отметь **галочками** конкретные моды и нажми «Сканировать» — обработаются только они.

### 3. Перевод

1. **Импорт перевода** → выбери готовый TSV (или `master.tsv`, если он уже переведён).
2. Программа сохранит результат в `master_ru_fixed.tsv`.
3. Открой интересующий мод двойным кликом — увидишь его строки в редакторе.

### 4. Цикл «нейронка → перевод → импорт»

1. **Экспорт для перевода** → сохрани `translation_<mod_id>.tsv`.
2. Отдай файл нейросети. Готовый промт — в `docs/prompt.md`.
3. Полученный файл → **Загрузить перевод**.
4. Программа сопоставит строки по `(path, line, col, kind, key, original)` и обновит `translated`.

> ⚠️ **Не редактируй TSV в Excel** — он ломает `mod_id` и кодировку. Используй Notepad++, VS Code или любой plain-text редактор.

### 5. Инжект

- **Бэкап** — сделать копии файлов, которые будут изменены.
- **Инжект** — применить все переводы.
- **Диагностика** — проверить, что реально встало.

Или точечно: **двойной клик по моду** → вкладка «Перевод мода» → **Применить мод** (с бэкапом и диагностикой только этого мода).

## Как это работает

### `.sbc` файлы

Строки вроде:

```
<DisplayName>Large Cargo Container</DisplayName>
<Description>Can store items.</Description>
```

Заменяются на:

```
<DisplayName>Большой грузовой контейнер</DisplayName>
<Description>Может хранить предметы.</Description>
```

Теги **сохраняются** — в перевод пишется только внутренний текст.

### `.resx` файлы

Используются модами, которые тянут текст через ключи:

```
<data name="DisplayName_Block_ArmorPanel" xml:space="preserve">
  <value>Armor Panel</value>
</data>
```

Перевод подставляется в `<value>`, ключ не меняется.

### Ключи локализации

Строки вида `DisplayName_AIE_Comp_CombatBotMaterial` или `{LOC:SomeKey}` **не переводятся** — они ссылаются на другие файлы. Программа их пропускает при сканировании.

```
se-localization-tool/
├── se_gui.py                 # Основное приложение
├── docs/
│   ├── prompt.md             # Промт для нейронки
```

### Файлы, которые создаёт программа

- `<loc_dir>/master.tsv` — результат первичного сканирования.
- `<loc_dir>/master_ru_fixed.tsv` — рабочая таблица переводов.
- `<loc_dir>/master_ru_fixed.tsv.edit_backup_*` — бэкап TSV перед серией правок.
- `<mod_dir>/<file>.sbc.bak_YYYYMMDD_HHMMSS` — бэкап каждого `.sbc`/`.resx` перед инжектом.

## Промт для нейросети

Готовый промт лежит в `docs/prompt.md`. Скопируй его, приложи файл `translation_<mod_id>.tsv` — нейросеть заполнит колонку `translated`.

## Известные ограничения

- **Двойной клик по моду** загружает только его строки в редактор. Для смены мода ещё раз кликни по другому.
- **Ключи `{LOC:...}` и `DisplayName_*`** пропускаются при сканировании — их нельзя перевести в `.sbc`, они определены в `.resx`.
- **`.resx` кэшируются игрой**. После инжекта в `.resx` перезапусти игру — иначе изменения не подхватятся.
- **Моды с `IsDependency=true`** (CoreSystems, Defense Shields) тянутся в сейв автоматически, даже если ты их не выбирал в главном меню. Если мод падает — удаляй зависимость в `Sandbox.sbc` вручную.
- **Steam API блокируется в РФ**. Если моды не качаются — включи VPN.
